# Security policy

## Reporting a vulnerability
Please email **[security@your-domain]** (or open a private GitHub security advisory on this
repository). Include steps to reproduce, impact, and any proof of concept. Do not access other
users' data, run denial-of-service tests, or use social engineering.

We aim to acknowledge reports within 3 working days, give a remediation plan within 10, and credit
reporters who wish to be named. We will not pursue legal action for good-faith research that follows
this policy.

## Supported versions
Only the latest `main` branch is supported during the MVP phase.

## Security design
See `docs/threat-model.md`, `docs/architecture.md` (key management) and `docs/incident-response.md`.
TraceVault is designed to reduce risk, not eliminate it; no claim is made that it is unhackable.
